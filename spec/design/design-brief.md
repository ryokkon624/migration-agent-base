# デザインブリーフ — JPetStore モダン版（Claude Design 入力用）

> Phase 2→3 の橋渡し。**フロントエンド全体デザイン**を Claude Design で新規作成するための入力。
> 機能の出所: [`../backlog-map.md`](../backlog-map.md)（Epic→Feature）／[`../behavior/`](../behavior/)（各ドメイン挙動）。制約: [`../security-baseline.md`](../security-baseline.md)。

## 1. 何を作るか
**JPetStore**（ペットショップの EC）のモダン再構築の **Vue 3 SPA フロントエンド全体デザイン**。
クリーン/モダン・レスポンシブ・アクセシブル。ブランドは**新規**（レガシーの JSP の見た目は継承しない）。
**画像は nano banana で別途生成**するので、デザインは画像スロット/プレースホルダで表現する。

## 2. トーン & マナー
- モダン・クリーン・親しみやすい（ペット EC らしい温かみ）。
- **ライト/ダーク両対応**が望ましい。
- コンポーネント体系を1つに統一（"one system"／一貫したヘッダ・カード・フォーム・ボタン）。

## 3. 主要画面（フロー付き）
1. **ホーム/カタログトップ** — カテゴリ一覧、ヘッダに検索バー、ヒーロー
2. **カテゴリ → 商品一覧** — カードグリッド、サーバページング
3. **商品 → 在庫アイテム一覧**
4. **アイテム詳細** — 在庫状況表示、カート追加
5. **検索結果** — ヘッダ検索→カードグリッド、ページング（任意でカテゴリフィルタ）
6. **カート** — 明細・数量更新・削除・小計（数量のみ編集可）
7. **チェックアウト・ウィザード** — カート確認 →（配送/請求先）→〔任意〕別配送先 → 内容確認 → 確定
8. **注文完了**（サンキュー）
9. **注文履歴一覧 / 注文詳細**（本人のみ）
10. **サインオン / 新規登録 / アカウント・プロフィール編集**
- 導線: 保護ページ要求 → ログイン → **元の場所へ復帰**。

## 4. 機能スコープ（決定済）
- **含む**: カタログ閲覧・検索（ヘッダ検索＋グリッド＋サーバページング）／カート／注文（ウィザード・履歴・詳細）／アカウント・認証（登録・編集・ログイン）。
- **廃止**: バナー広告・MyList（おすすめリスト）・remoting/WS デモ。
- **支払**: 実カードは扱わない（**カード入力欄は置かない/プレースホルダ明示**。実カード番号は保存しない）。

## 5. UI に効く制約（secure-by-default 由来）
- **認証**: JWT を **httpOnly Cookie** に保管（フロントは**トークンを JS に持たない＝localStorage 禁止**）。ログイン維持・ログアウトあり。
- **フォームは CSRF 前提**（トークン）。状態変更は明示ボタン（GET リンクで確定しない）。
- **エラー表示**: ログイン失敗は**一律メッセージ**（ユーザ名を推測させない）。不正入力は分かりやすいインラインエラー。
- 機微入力は最小（実カードなし）。

## 6. 画像ニーズ（nano banana で生成予定・スロットだけ用意）
- カテゴリのヒーロー/アイコン: Fish / Dogs / Cats / Reptiles / Birds
- 商品/アイテムのサムネイル（モダンな商品写真調）
- 空状態・エラーのイラスト（任意）

## 7. 使い方
本ブリーフ（＋必要なら backlog-map の Feature 一覧）を Claude Design に渡してデザインを生成 → 出力をこの `spec/design/` に置き、PO が Story/AC を実画面参照で書く／Phase 3 の実装土台にする。
