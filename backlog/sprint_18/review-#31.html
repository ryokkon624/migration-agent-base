問題

IDE（VS Code / Eclipse JDT）が、4ファイル・計6件のストリーム処理におけるメソッド参照（BiFunction/Function）に対して "Null type safety" 警告を出していた。Gradleビルド自体は失敗しない（本repoのGradle lintはspotlessのみ・null解析ツール未導入）が、JDK標準の関数型インターフェイスに対するメソッド参照でJDTの型推論制約に起因するfalse-positive寄りの警告で、実装中の警告ノイズになっていた。
