Sprint 19 Review

#36 — テーマ（ライト/ダーク/システム連動）を
切り替え・DB保持できるようにする

Sprint 19 #36 feature cross-repo frontend backend database

なぜこの改修が必要だったか

背景

ダーク配色トークンは main.css に既に完備（:root=ライト／:root.dark=ダークのフルセット・@media (prefers-color-scheme: dark)のOS追従も実装済み）だったが、「切替UI＋永続化＋適用ロジック」が一切無く、ユーザーは配色を選べなかった。

改修前
ダーク配色トークンは完備・切替UIが皆無
ヘッダーに再利用可能なdropdown部品が無い
m_profileにテーマ列が無い
/api/auth/login・/meは{username, roles}のみ
→
改修後
ヘッダーのアイコン+ドロップダウンで即時切替
新規共通部品SettingsDropdown.vueを導入
m_profile.color_scheme_preferenceで永続化
login/me応答にテーマ・言語を含め跨デバイス追従
database

V00_000_013でm_profileにcolor_scheme_preference VARCHAR(20) NOT NULL DEFAULT 'system'を追加。既存行は自動的にsystemで埋まる。

backend

AccountEdit往復（GET/PUT /api/account）にcolorSchemePreferenceをthreading。/api/auth/login・/api/auth/me共通のLoginResponseを拡張し、DB権威の設定をSPAへ返す。

frontend

usePreferencesStore（Pinia単一ソース）を新設。ヘッダーのドロップダウン・AccountEditの両方から編集可能にし、localStorage・DOM・i18nへ即時適用する。
